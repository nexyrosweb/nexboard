# Internationalization (i18n)

NexBoard keeps a **lightweight custom i18n layer** (no i18next dependency) aligned with the existing React + TypeScript stack.

## Active locales

| Code | BCP 47 | Label |
|------|--------|--------|
| `fr` | `fr-FR` | Français (default for new installs) |
| `en` | `en-GB` | English |
| `es` | `es-ES` | Español |
| `de` | `de-DE` | Deutsch |
| `it` | `it-IT` | Italiano |
| `pt` | `pt-PT` | Português |

Legacy `ja` values stored in settings / localStorage are normalized to `en`.

## Where things live

```text
client/src/i18n/
  config.ts                 # LOCALES, flags, BCP47, normalizeLocale()
  translations.ts           # dictionaries merge + translate()
  locales/
    fr|en|es|de|it|pt/
      navigation.ts
      common.ts
      dashboard.ts
      clients.ts
      projects.ts
      quotes.ts
      invoices.ts
      expenses.ts
      tasks.ts
      calendar.ts
      notifications.ts
      settings.ts
      authentication.ts
      errors.ts             # errors.* + validation.* + lang.*
      index.ts
```

UI entry point: `LanguageSwitcher` in the topbar (Language → Theme → Notifications).

## Persistence

1. `localStorage` key `nexboard-locale` (preferred on load)
2. Server setting `locale` (synced when changing language from the switcher or Settings)

Changing language does **not** reload the page, reset filters, or alter stored invoice currencies/amounts. Only display formatting uses `Intl`.

## Adding a language

1. Add the short code to `LOCALES` / `LOCALE_META` in `client/src/i18n/config.ts`.
2. Copy `client/src/i18n/locales/en/` to `locales/{code}/` and translate every module (same keys as English).
3. Register the dictionary in `client/src/i18n/translations.ts`.
4. Allow the code in `server/src/routes/settings.ts` (`LOCALES` set).
5. Update README feature list and this doc.
6. Run `npm run build -w nexboard-client` and smoke-test the switcher (keyboard, dark/light, mobile).

Optional helper scripts under `scripts/`:

- `extract-i18n.mjs` — split a monolithic dictionary into modules
- `dump-i18n-pack.mjs` / `write-it-pt-modules.mjs` — regenerate locale modules from JSON packs

## Formatting

Use `formatDate` / `formatCurrency` / `formatNumber` from `client/src/utils/format.ts`.  
They follow the active locale via `setFormatLocale` (wired from `I18nProvider`).
